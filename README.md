# StillTime

A text adventure about grief, self-acceptance, and survival at the end of the world.

Updated post-jam with some fixes (code bugs and typos).
The game is now hosted on GitHub pages and embedded in Itch (this was not the case during the jam of course).

Dev build can be played here: https://vcmiller.github.io/StillTime/dev/
